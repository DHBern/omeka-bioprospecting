# omeka-bioprospecting

Static archive of the Omeka S site **Westafricanbioprospecting**, formerly at
`https://omeka.unibe.ch/s/bioprospecting`.

- Snapshot: 2026-11-20, mirrored with `tools/mirror.sh` from [DHBern/omeka-admin](https://github.com/DHBern/omeka-admin).
- Paths are kept as in Omeka (`/s/bioprospecting/page/…`, `/item/…`, `/media/…`), so old URLs can be forwarded 1:1.
- Images are served from the `large` derivatives; small non-image originals (PDFs) are included. Search and login are disabled.
- Original high-resolution files remain in the v3 archive.
